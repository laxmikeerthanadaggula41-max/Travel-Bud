
# 🌍 Travel Bud – Discover Your Next Adventure

Travel Bud is a travel planning website that helps users explore destinations, discover places based on their travel interests, manage their wishlist, and plan trips according to their budget.

## ✨ Features

- 🏞️ **Explore Destinations:** Discover beautiful destinations such as Manali, Goa, Munnar, Bali, and Paris.
- 🔍 **Search Destinations:** Search for places by destination name, country, category, or description.
- 🧭 **Category Filters:** Explore destinations based on interests such as nature, beaches, adventure, culture, family trips, and solo travel.
- ❤️ **Wishlist:** Add your favourite destinations to your wishlist.
- ↕️ **Sorting:** Sort destinations by budget or rating.
- 💰 **Budget Calculator:** Find destinations that fit your travel budget.
- 🗓️ **Trip Planner:** Create and save your trip ideas.
- 💾 **Local Storage:** Keep wishlist items and saved trips in your browser.
- 📱 **Responsive Design:** Enjoy the website on different screen sizes.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactive features and functionality
- Browser Local Storage – Saving wishlist and trip information

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
4. Explore destinations and try the search, filters, wishlist, and trip-planning features.

## 🎯 Project Objective

The objective of Travel Bud is to make travel discovery and basic trip planning easier by bringing destination exploration, interest-based filtering, budgeting, and trip saving together in one simple website.
